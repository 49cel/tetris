# Data Structures Project

This is a remake of the game 'Tetris' using the data structure concepts, built using C++

To run it:

1. Clone the repo using `git clone https://github.com/49cel/tetris`

2. Compile the build using `make` (Ensure you have all the dependencies sorted out)

3. You can now run it using `tetris` or `./tetris` in your terminal (Kitty is preferred over other native terminals)
